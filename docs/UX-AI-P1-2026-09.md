# P1 接口与升级说明

配套前端 eddie，完整交付/验收说明在 WatchAlert-web/docs/RELEASE-P1-2026-09.md。

- POST /api/w8t/silence/silencePreview：角色权限 silencePreview。租户来自认证上下文，校验故障中心归属、名称/原因/标签/有效时间；返回 previewHash、previewAt、total、samples（最多 5）、truncated。对当前非恢复事件使用与通知抑制相同的 Label 匹配器。
- silenceCreate / silenceUpdate 接收可选 previewHash / previewAt。携带时校验 5 分钟时效与当前条件/匹配指纹/原配置摘要；不一致则拒绝写入。新前端及新 Agent 提案始终携带。为旧 API 客户端兼容，完全省略时不强制预览，但基本校验仍执行。
- 当前快照不是未来影响上限或写锁；权限独立检查。没有新增数据库列。写成功返回对象供前端展示 ID，不声明实际通知已抑制。
- 先保存 SQL 再推送缓存；修复未来静默 status=0 的赋值及 SQL 零值更新；通知匹配还检查实际开始和结束时间。缓存仍沿用既有同步/调度机制，不具备跨 SQL/Redis 事务。
- POST /api/w8t/agent/diagnostics：角色权限 agentDiagnostics。Go → Agent POST /v1/diagnostics → Go GET /api/w8t/internal/agent/health / DeepSeek GET /models。内部端点均要求 X-WatchAlert-Agent-Token，不生成聊天、不执行业务 Tool。限制超时、响应大小、重定向与输出代码。
- 未配置、不可达、鉴权失败、模型未列出、环境变量方式未探测分别返回明确状态。模型列表通过不证明推理可用、余额充足或 Prometheus 数据正常。
- 新角色权限需管理员按职责授予；不自动扩大任何用户的生产写授权。silencePreview 能查看当前租户匹配告警摘要，应按同等告警读取权限管理。

需要更新 Go、agent-service 和前端三组件。先测试环境，保留旧 tag，沿用配置中的内网地址/Token/加密 Key，不将凭据写入文档。未执行生产部署或真实模型推理。
