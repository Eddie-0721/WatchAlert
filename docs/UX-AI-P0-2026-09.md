# UX / Agent P0 后端变更

配套前端 WatchAlert-web 的 docs/UX-AI-OPTIMIZATION-2026-09.md 与 docs/RELEASE-2026-09.md。

## 当前告警 API

GET /api/w8t/event/curEvent 新增可选 queue 与 includeSummary=true。

queue 值为 attention / processing / suppressed / observing / all。与既有生命周期和认领/静默字段组合使用，不把“静默”当作“恢复”。分页 list 与 total 属于选定队列；summary.queues 在同租户、同搜索及环境/服务筛选下，于选择队列和分页前计算。summary.environments / services 为该范围可用选项。

省略新增参数保留旧查询行为。Agent 查询在分页前应用可信环境/数据源限制，不接受浏览器或模型输入可信范围字段，不返回未授权范围汇总。当前实现仍遍历缓存事件计算摘要，不是大规模预聚合方案。

## Agent 安全与证据

- 每次 Tool 调用取当前权限，与签名 token 原范围求交集；互斥范围拒绝，不把空交集解释为不限制。
- PromQL AST 检查全部向量选择器。授权环境需精确相等条件；数据源连接上的描述标签不能替代指标隔离。共享连接可以按授权 ID 发现。
- 确认操作重新读取开关、工具权限、环境/数据源范围与生产写策略。重新验证目标及有效期；修改/删除的静默原配置已变化时拒绝旧预览。
- 不限环境或无法明确判定为非生产的自定义名称，需要显式允许生产写。管理员需核对配置，不能为修复 UI 问题而放宽生产权限。
- 静默正则先验证语法；当前告警认领范围从实际 Redis 事件读取，不误查 SQL 历史表。
- 会话详情按持久化操作状态刷新证据状态，过期的待确认项显示过期。
- Python Agent 返回查询时间、ID 引用、实际查询参数、分页范围/截断提示；不把查询成功当作结论验证。不加入凭据到新证据字段。

无新增数据库列。需更新 Go 服务与 agent-service 镜像，再更新配套前端。完整部署验收、已知全量测试问题与后续范围见前端升级说明。CI 不再随 eddie 推送自动发布上游 cairry Docker Hub 镜像。
