# 拨测调度生命周期与共享容量

日期：2026-10-10。后端基线 `972d622`，分支 `codex/probe-dispatch`。前端与独立 Agent 未改动。

## 代码问题与修复

原 `Stop` 取消后立即删除登记，紧接着的 `Add` 会创建新 goroutine，无法保证旧执行已经退出。原启动路径还为每个规则额外创建一次仅用于 `Add` 的 goroutine。告警评估的查询槽不覆盖拨测；多个规则和即时拨测没有共享运行上限。

- 每个规则保留一个 worker，停止后直到旧执行真实返回才释放登记。Stop/Add 期间复用该 worker 的最新配置，连续更新合并中间版本；不启动第二个同规则循环。仍启用时直接重复 Add 继续返回原有重复错误。
- 旧配置退出后才创建新周期 context 和定时器，新配置仍立即执行一次；普通轮次保持原 ticker 行为，错过的 tick 不形成任务队列。正在等待容量的旧配置也随取消退出。
- 一个周期 panic 释放容量并记录错误，不递归重启旧版本，也不让旧 panic 覆盖较新配置。父 context 结束后清理登记，不接受新任务。
- 每进程共享拨测容量，定时周期持有槽位直到全部目标及 remote write 返回；即时拨测使用同一容量。定时 worker 可取消地等待，不额外创建等待 goroutine；即时入口容量满即返回 `拨测任务繁忙，请稍后重试`，避免新增 HTTP 等待队列。
- 获取后再检查取消，释放是幂等的；取消、正常返回及 panic 都回收槽位。
- 启动按顺序安装规则 worker，不再额外创建 N 个短命启动 goroutine；仍尝试全部规则，汇总无效规则错误，不因第一条错误跳过后续合法规则。启动 SQL 接收根 context。

GetActiveRules 表示已启用/等待新配置的逻辑规则数，不包含已请求停止但仍退出中的 worker，不代表当前网络并发数。Stop/StopAll 仍是请求取消，不阻塞接口等待远端完成。

## 可选配置

```yaml
Probing:
  maxConcurrentRuns: 32
```

省略或非正值采用 32，正值最多 256；首次使用时初始化，修改后重启。与已有 Evaluation 配置的默认/收敛方式一致，不升级依赖。该上限独立于告警评估和通知预算，不是所有网络请求共享上限，也不是每秒速率限制；多进程/副本需要计算总容量。

长目标列表或慢写入会持有一个周期槽位；高负载会延迟后续周期，即时请求可能被拒绝。这里没有公平调度/SLA 或“32 就适合所有生产规模”的承诺，也未限制每条规则的全部指标字节量。请结合实际评估延迟、连接数和内存调整。

## 本地验证

新增 10 个顶层测试最终连续 10 轮通过：

- 不合作的旧周期在取消后仍等待、再抛出 panic：反复 Stop/Add 只启动最新版本，同规则执行峰值为 1，登记最终清理，槽位回收。
- 容量满时的旧等待者被取消，释放容量后只执行最新配置。
- 80 个规则任务的执行峰值最多 32；StopAll 后运行者和等待者均退出，32 个槽位全部可再次获取。
- 40 个实际本地 HTTP 拨测：32 个慢请求占满容量时，其余规则不能开始网络请求，即时申请也被拒绝；停止后 worker 退出。
- 即时服务在容量满时返回明确错误且不访问目标，释放一个槽位后正常 HTTP 结果保持原形状，结束后容量可再次获取。
- 容量默认/上下界、排队截止、预取消、重复释放；父任务取消后 idle worker 清理；Viper 配置解析。
- SQLite 启动读取含合法、非法、禁用规则：合法规则仍真实探测，非法项汇总报告，禁用项不启动；父任务取消后启动查询返回取消。

后端相关包非缓存回归、go vet 和 `go build ./...` 均通过。没有真实外部网络目标、生产压测、Linux 镜像或 Go race 验证，不用本地峰值断言生产吞吐提升。

## 发布与剩余边界

仅更新后端镜像；配置可省略，数据库/Redis/前端协议无迁移，API 繁忙错误沿用既有失败响应。已有前端错误处理会展示其文本，未宣称本批完成浏览器验收。前端/Agent 未改，未部署生产。

保留上批旧拨测配置合法性检查要求。取消不能撤销远端已接受的写入，进程预算不能阻止其他副本发起同规则任务，实际 ICMP/生产负载仍需验证。

本轮继续核对代码发现两个下一批候选：Prometheus remote-write 错误响应仍 `io.ReadAll` 且 timeout 取数据源配置，零值时没有整体时限；前端即时拨测 POST 尚未传递 AbortSignal，离开页面不一定中止网络任务。需要分别验证后修复，不能把本批后台调度通过当作端到端取消全部完成。
