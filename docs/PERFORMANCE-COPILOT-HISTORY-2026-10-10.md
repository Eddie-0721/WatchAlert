# Copilot 长会话加载优化

## 范围与改动

前后端开发分支：`codex/copilot-history-pagination`。独立 Agent 不改动，模型上下文预算与工具调用流程不变。

此前恢复会话会读取全部消息、全部操作记录（包括 Payload/Result），并渲染全部 Markdown。现改为初次读取最新 50 条，用户可加载更早消息；不删除或截断已保存的历史。

- `GET /api/w8t/agent/sessionGet` 保留 `sessionId`，新增可选 `limit`（默认 50，最多 100）和 `before`（不透明游标）。非法参数返回错误，不退回无界查询。
- 响应保留 `session/messages`，新增 `hasMore/nextCursor`。通过 `(created_at, id)` 倒序读取 `limit + 1`，每批正序返回；不执行总数 COUNT 或深 OFFSET。
- 游标校验所属会话，权限仍由租户和会话所有者校验；管理员也不能越过租户。查询使用请求上下文及最长 10 秒超时。
- 只查询当前页证据引用的操作 ID，每组最多 100 个，仅取 `id/status/expires_at`，保留已执行/已过期状态更新；不读取其他操作与完整 Payload/Result。
- 前端提供“加载更早消息”和失败重试；失败保留当前内容与游标，加载成功保留阅读位置。切换或新建会话取消请求并拒绝迟到结果，连续点击不会重复请求。
- frontend-design 技能用于复用既有字体、配色和按钮，不改变品牌、导航、业务权限或操作确认流程。

## 验证

- 后端新增 3 组测试连续 10 次通过：123 条消息跨页、同秒边界、翻页期间新增消息、无重复/遗漏、空页/最大页、非法游标、用户/租户隔离、取消及关联操作查询字段/数量。
- 后端相关包回归、`go vet ./internal/services ./api ./internal/types`、`go build ./...` 通过。未运行访问固定外部环境的 provider 示例测试。
- 前端类型检查与生产构建、19 项单元测试通过。
- 浏览器性能回归 11 项、Copilot 权限/证据/场景返回/诊断回归 5 项通过；包含 1440px 和 390px 分页、失败重试、阅读位置、迟到请求隔离以及原有流式/编辑器行为。手机截图已查看。
- 首次因 Playwright 自带浏览器缺失未能启动，改用本机 Chrome 后实际运行通过。浏览器使用本地预览与模拟 API，不代表真实后端联调或生产验收。

## 发布与回滚

前后端须配套发布，建议先前端再后端：新前端兼容旧响应；旧前端连接新后端只能显示最新 50 条，没有早期历史入口。无需更新 Agent 镜像，无新增表结构或密钥配置。回滚时先回滚后端再前端。代码推送不代表已上线。

复用已有只读索引计划中的 `idx_perf_agent_history(tenant_id, session_id, created_at, id)`，本批不自动建立索引。未安装复合索引时，数据库仍可能扫描/排序较多行；限制返回条数不等于消除了数据库扫描。

## 保留边界

- 手动反复加载和持续发送仍会增加 DOM，尚非无限会话虚拟列表；限制的是条数，单条历史内容可能很大，不承诺固定响应字节预算。
- 历史时间戳为秒级，没有可靠写入序号；ID 提供稳定分页，不能还原同秒并发消息的真实先后。未改写历史或新增顺序迁移。
- 会话列表仍只展示最近 50 个会话，未增加会话列表分页。
- 没有真实 MySQL/Redis 压测、容器构建或生产部署；没有生产耗时提升比例结论。静态资源代理、容量验证等整体性能待办继续保留。
